# VINA Coffee — Data Centre v0.1 (інтерактивний прототип)

Це **перший демонстраційний інтерфейс**, а не production CRM. У ньому є огляд, працівники, історія змін, склад власника та журнал дій. Дані зберігаються **лише в localStorage браузера**. Демодані не синхронізуються між пристроями, не мають авторизації та не підходять для реальних персональних даних.

## Локальний запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

## Cloudflare

У `wrangler.jsonc` вже зазначено `"name": "vinacoffee"`. **Не запускайте `npm run deploy`, поки не перевірите налаштування наявного Worker `vinacoffee`**, бо команда може замінити його поточний код.

Після перевірки інтеграції GitHub, тестування та підтвердження заміни Worker:

```bash
npx wrangler login
npm run deploy
```

Маршрут `/api/health` повертає JSON-стан прототипу.

## Наступний production-етап

1. Серверна автентифікація власника з MFA та RBAC.
2. База даних, міграції, журнал аудиту, резервні копії.
3. Реальне створення працівників, сесії, відкликання доступу.
4. Серверний облік змін, підтвердження завершення, автозакриття за часовим поясом закладу.
5. Staff та Telegram Mini App, бонусні транзакції й захист телефонів (AES-256-GCM + HMAC-пошук).
6. Запити про нестачу та push, інвентаризація власника.

**Не використовуйте прототип для реальних даних гостей чи працівників.**
